# Minesweeper 掃海図 (minesweeper_2)

`index.html` をブラウザで開くだけで動きます（サーバー不要）。

- `engine.js` … 盤面生成・論理ソルバ・地雷確率の厳密計算・ゲーム状態。DOM に依存しません。
- `game.js` … 描画（canvas）と操作。
- `test/verify.js` … `node test/verify.js`（`--quick` で短縮）。確率を総当たりと照合し、
  推測なし盤面を独立したソルバで解き直し、生成時間を計測します。

## 元の版からの主な変更

- 推測なしで解ける盤面だけを配るモード（設定で切り替え）
- 地雷確率の表示（「確率」ボタン / P キー）。使ったゲームはベストタイムに記録されません
- 数字クリック・左右同時押し・中クリックで周囲をまとめて開く
- タイマー、残り地雷数、ベストタイム保存、一時停止、ライト / ダーク表示
- 元の版にあった Exit / Quit（`window.close()`）はブラウザでは動作しないため外しました

## 確認ダイアログ・縦長盤面・離脱警告

- **確率表示の警告** … ゲームごとに、最初に「確率」をオンにするとき（ボタン / P キー）だけ画面中央に確認を出します。
  「表示する」を選ぶまで確率は表示されず、同じゲーム中の 2 回目以降の切り替えでは出ません。
  確率を表示したゲームはクリアしてもベストタイムに記録されません（あとで消しても戻りません）。
  新しい盤面・やり直しのたびに確率表示はオフに戻ります。
- **盤面を捨てる前の確認** … 進行中（最初のマスを開いた後で、勝敗がつく前）に「新しい盤面」ボタン / N キー /
  設定の「この設定で始める」を使うと確認を出します。R キーでのやり直しも進行を失うので同じ扱いです。
  まだ何も開いていない盤面と、終了した盤面では確認しません。確認中はタイマーを止めます。
- **縦長の上級盤面** … 上級（30×16、地雷 99）は、新しい盤面を作る時点で画面が縦長（高さ > 幅）なら
  16×30 で作ります。大きさを決めるのは盤面を作るときだけで、プレイ中に端末を回転しても盤面は変わりません。
  設定の難易度一覧とヘッダーには、実際に作られる大きさを表示します。
  ベストタイムは 30×16 と 16×30 で共通です（マス数も地雷数も同じで、盤面を 90 度回しただけのため。
  保存キーは従来どおり `16x30x99` / `16x30x99-ng` なので、これまでの記録もそのまま使われます）。
- **タイトルのリンクと離脱警告** … ヘッダーの「Minesweeper」はページ自身へのリンクで、押すと読み込み直します。
  進行中のゲームがある間だけ `beforeunload` を登録し、再読み込み・タブを閉じる・別ページへの移動の前に
  ブラウザ標準の確認が出ます（文言はブラウザが決めます）。
