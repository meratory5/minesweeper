# Minesweeper 掃海図 (minesweeper_2)

`index.html` をブラウザで開くだけで動きます（サーバー不要）。

- `engine.js` … 盤面生成・論理ソルバ・地雷確率の厳密計算・ゲーム状態。DOM に依存しません。
- `game.js` … 描画（canvas）と操作。
- `test/verify.js` … `node test/verify.js`（`--quick` で短縮）。確率を総当たりと照合し、
  推測なし盤面を独立したソルバで解き直し、生成時間を計測します。

## 元の版からの主な変更

- 推測なしで解ける盤面だけを配るモード（設定で切り替え）
- 地雷確率の表示（「確率」ボタン / P キー）。使ったゲームはベストタイムに記録されません
- 数字クリック・左右同時押し・中クリックで周囲をまとめて開く
- タイマー、残り地雷数、ベストタイム保存、一時停止、ライト / ダーク表示
- 元の版にあった Exit / Quit（`window.close()`）はブラウザでは動作しないため外しました
